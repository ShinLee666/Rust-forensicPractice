# Rust 练手小项目 —— 电子数据取证竞赛方向

一个面向**电子数据取证竞赛**的 Rust 练手项目合集。由易到难、循序渐进，每个小项目都对应取证竞赛中的真实场景，帮助你在实战中掌握 Rust。

> 📖 配套教程：本项目的 Rust 语法学习教程已分享至 [www.speedforensic.cn](https://www.speedforensic.cn)，欢迎免费学习。

## 为什么选择 Rust 做取证竞赛工具？

在电子数据取证竞赛中，经常需要现场编写解题脚本或制作小工具（终端工具 / GUI 工具）——分析文件格式、处理十六进制数据、解编码、计算校验值等。

- **性能出色**：无 GC、接近 C/C++ 的运行效率，处理大文件无压力
- **单文件分发**：编译后直接得到一个可执行文件，赛场上拷过来就能跑
- **安全可靠**：所有权机制让内存错误在编译期暴露，工具更稳定
- **生态丰富**：`clap`、`tauri` 等库可以快速做出专业的 CLI / GUI 工具
